Icon Picker Widget

A beautiful visual icon picker widget for Odoo 19 — select Font Awesome icons with a single click instead of typing class names manually.

Odoo 19 OWL Component Font Awesome

Key Features

Everything you need to manage icons effortlessly in your Odoo backend.

Visual Icon Picker

Open Odoo's built-in Media Dialog to browse and select icons visually — no more guessing class names.

Live Preview

See a real-time preview of the selected icon rendered right next to the form field.

Easy Integration

Just add widget="icon_picker" to any Char field in your XML view — that's it!

Multiple Icon Libraries

Supports Font Awesome, Fontello, and IcoMoon icons out of the box for maximum flexibility.

OWL Component

Built with Odoo 19's modern OWL framework for fast rendering and reactive state management.

Works on Any Char Field

A generic widget that can be attached to any Char type field across all Odoo models.

How It Works

Get started in 3 simple steps.

1
Install the Module

Download and install Icon Picker Widget from the Odoo Apps Store. No additional configuration is needed.

2
Add the Widget to Your View

In your custom module's XML view, add the widget="icon_picker" attribute to any Char field where you want icon selection.

3
Pick Your Icons!

Click the "Pick an Icon" button in the form view. Browse the icon library visually, select an icon, and it's saved automatically.

XML View Example: 
<!-- Add icon picker to your form view -->
<record id="view_my_model_form" model="ir.ui.view">
    <field name="name">my.model.form</field>
    <field name="model">my.model</field>
    <field name="arch" type="xml">
        <form>
            <sheet>
                <group>
                    <field name="name"/>
                    <field name="icon" widget="icon_picker"/>
                </group>
            </sheet>
        </form>
    </field>
</record>
